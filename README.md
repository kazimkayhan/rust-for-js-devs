# Rust from JavaScript: Zero to Hero

A single, comprehensive Markdown tutorial that teaches **Rust from scratch to advanced topics**, written for developers who already know **JavaScript (ES6+)**.

## Main guide

→ **[RUST_FROM_JS_ZERO_TO_HERO.md](./RUST_FROM_JS_ZERO_TO_HERO.md)**

It follows the curriculum of the official **[Rust by Example](https://doc.rust-lang.org/rust-by-example/)** book and explains every major topic with:

1. Plain English
2. A JavaScript mental model / analogy
3. Rust examples
4. JS equivalents when useful
5. Common pitfalls for JS developers

## What's covered

All 24 top-level Rust by Example chapters, plus extras:

- Install / `cargo new` mapped to npm/node
- Ownership, borrowing, and lifetimes (extra depth for JS devs)
- Practice checklist
- JS ↔ Rust cheatsheet

See [`rbe-SUMMARY.md`](./rbe-SUMMARY.md) for the full RBE table of contents this guide tracks.

## How to use

1. Install Rust with `rustup`.
2. Open `RUST_FROM_JS_ZERO_TO_HERO.md` and work section by section.
3. Create a practice crate (`cargo new rust_playground`) and type the examples yourself.
4. Spend extra time on **ownership, borrowing, and lifetimes** (section 16).
5. Follow the checklist in section 25.
